# План: Приведення React фронтенду у відповідність з Django шаблонами

## Мета
Привести React компоненти (`frontend-react/src/`) до вигляду Django шаблонів (`templates/`), оскільки Django шаблони є "продакшн" версією.

## Порівняння та відмінності

### 1. Header (`partials/header.html` vs `MainHeader.jsx`)
**Django:**
- Простіший хедер з `bg-white shadow-md`
- Кнопки: "Зареєструватися" (border) та "Увійти" (filled)
- Соцмережі: Facebook, Instagram, TikTok (прості іконки)
- Авторизація: `{% provider_login_url 'google' %}` для Google auth

**React (поточний):**
- Складніший хедер з `border-b border-slate-200/70 bg-white/95 backdrop-blur-md`
- Додаткові стилі border/shadow
- Кнопки: "Створити кабінет" та "Увійти"
- Соцмережі: ті ж, але з rounded-full border стилями
- Авторизація: через `data-google-auth` data attribute

**Що змінити:**
- Спростити стилі хедера до `bg-white shadow-md`
- Змінити кнопки на "Зареєструватися" / "Увійти"
- Спростити стилі соцмереж
- Перевірити Google auth кнопку

### 2. Footer (`partials/footer.html` vs `MainFooter.jsx`)
**Django:**
- Простий центрований футер
- Тільки лого + теглайн + соцмережі + копірайт
- `bg-coolSage py-6 text-center`

**React (поточний):**
- Складний 3-колоночний layout з навігацією та контактами
- `bg-coolSage text-white` з grid layout
- Додаткова навігація та контактна інформація

**Що змінити:**
- Повністю переписати `MainFooter.jsx` на простий центрований варіант з Django

### 3. Hero Section (`hero.html` vs `HomeHeroSection.jsx`)
**Django:**
- `hero.html` порожній файл (0 рядків)

**React:**
- Повноцінний hero з відео фоном та пошуковою формою

**Що змінити:**
- Оскільки Django hero.html порожній, можливо він використовується через інший partial або React hero є правильним
- Потрібно перевірити як hero рендериться в проді

### 4. About Section (`partials/about.html` vs `HomeAboutSection.jsx`)
**Django:**
- `bg-[#758F8E]` inline style
- Текст з `—` (em dash)

**React:**
- `style={{ backgroundColor: '#758F8E' }}` inline style
- Текст з `-` (hyphen)

**Що змінити:**
- Замінити `-` на `—` в React компоненті

### 5. Contact Section (`partials/contact.html` vs `HomeContactSection.jsx`)
**Django:**
- Проста форма без labels
- `{% csrf_token %}` для CSRF
- Button text: "Надіслати повідомлення"

**React:**
- Форма з labels та validation
- CSRF token через `onSubmit` handler
- Button text: "Надіслати повідомлення" / "Надсилання..."

**Що змінити:**
- Прибрати labels з форми
- Спростити стилі форми

### 6. Featured Properties (`HomeFeaturedPropertiesSection.jsx`)
- React має swiper для мобільної версії та grid для десктопу
- Django шаблон `featured_properties.html` потрібно перевірити

## План дій

### Етап 1: Header (пріоритет високий)
1. Оновити `MainHeader.jsx` щоб відповідав Django `header.html`
2. Спростити стилі (прибрати backdrop-blur, складні border/shadow)
3. Змінити текст кнопок на "Зареєструватися" / "Увійти"
4. Спростити стилі кнопок соцмереж

### Етап 2: Footer (пріоритет високий)
1. Повністю переписати `MainFooter.jsx` на простий центрований варіант
2. Залишити тільки: лого, теглайн, соцмережі, копірайт

### Етап 3: Home Page (пріоритет середній)
1. Перевірити hero секцію (чи потрібен React hero якщо Django порожній)
2. Оновити `HomeAboutSection.jsx` (em dash замість hyphen)
3. Спростити `HomeContactSection.jsx` (прибрати labels)

### Етап 4: Інші сторінки (пріоритет низький)
1. Перевірити search page
2. Перевірити property detail page
3. Перевірити likes page

## Етап 5: Realtsoft CRM Інтеграція (пріоритет високий)

### Існуючий код
- `house/services/realtsoft_client.py` - API клієнт (HMAC автентифікація)
- `house/management/commands/sync_crm_properties.py` - Команда sync
- `house/models.py` - Модель `ExternalProperty`
- Налаштування в `.env`: `REALTSOFT_CRM_URL`, `REALTSOFT_API_KEY`, `REALTSOFT_SECRET_KEY`

### API Документація Realtsoft
- **Base URL**: `https://crm-dominium.realtsoft.net/api/`
- **Автентифікація**: HMAC підпис (MD5 хеш параметрів + SHA1 підпис секретним ключем)
- **Headers**: `auth: {api_key}:{signature}`
- **Основні методи**:
  - `estate/index` - Пошук об'єктів нерухомості
  - `client/index` - Пошук клієнтів
  - `client/create` - Створення клієнта
  - `inquiry/create` - Створення запиту

### Що потрібно зробити
1. **Перевірити та виправити `realtsoft_client.py`**:
   - Перевірити HMAC підпис (можлива помилка `hmac.new` vs `hmac.HMAC`)
   - Протестувати з'єднання з CRM
   - Додати обробку помилок

2. **Оновити `sync_crm_properties.py`**:
   - Додати автоматичну синхронізацію (celery/cron)
   - Покращити обробку помилок
   - Додати логування

3. **Налаштувати середовище**:
   - Отримати API ключі від CRM
   - Оновити `.env` файл
   - Увімкнути `REALTSOFT_SYNC_ENABLED=1`

4. **Протестувати синхронізацію**:
   - Запустити `python manage.py sync_crm_properties --dry-run`
   - Перевірити дані в базі
   - Перевірити відображення на сайті

## Верифікація
1. Запустити Django сервер (`python manage.py runserver`)
2. Запустити React dev server (`cd frontend-react && npm run dev`)
3. Порівняти вигляд Django шаблонів та React SPA на кожній сторінці
4. Перевірити працюючість навігації, форм, авторизації
5. Протестувати синхронізацію з Realtsoft CRM
