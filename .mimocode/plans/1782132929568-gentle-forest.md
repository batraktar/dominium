## Що потрібно зробити

### Крок 1: Realtsoft API Client (Python)

**Файл: `house/services/realtsoft_client.py`** — НОВИЙ

Реалізація Python-аналога PHP SDK (https://github.com/taral14/realtsoft-client-api):

```python
class RealtsoftClient:
    def __init__(self, url, key, secret): ...
    def call(self, method, params=None, http_method='GET'): ...
    def _generate_sign(self, method, params): ...
    def search_estate(self, **filters): ...
    def find_client(self, phone=None, email=None): ...
    def create_client(self, phones, name, email, responsible_user_id=1): ...
    def create_inquiry(self, **data): ...
```

Аутентифікація:
- Header: `auth: {API_KEY}:{signature}`
- Signature: `base64(hmac_sha1(method + md5(query_string_sorted), secret_key))`
- URL: `https://crm-dominium.realtsoft.net/api/{method}`

### Крок 2: Модель для зовнішніх об'єктів

**Файл: `house/models.py`** — додати нову модель + розширити Property

Нова модель `ExternalProperty`:
- `crm_property_id` — int, унікальний ID з CRM
- `property` — FK → Property
- `crm_url` — URL об'єкта в CRM
- `raw_data` — JSON (оригінальні дані для історії)
- `last_synced` — DateTime
- `sync_status` — choices (synced/error/pending)

Розширення `Property`:
- `external_source` — CharField (realtsoft/manual/import)
- `external_id` — CharField (унікальний ID з зовнішнього джерела)
- `price_currency` — CharField (USD/EUR/UAH, default USD)

### Крок 3: Management Command

**Файл: `house/management/commands/sync_crm_properties.py`** — НОВИЙ

Логіка:
1. Підключається до CRM через `RealtsoftClient`
2. Викликає `estate/index` з параметрами:
   - `status=active` (обов'язково)
   - `per-page=150` (максимум)
   - Пагінація (сторінка 1, 2, 3...)
3. Для кожного об'єкта з CRM:
   - Шукає `Property` з `external_id=crm_id` та `external_source=realtsoft`
   - Якщо не знайдено — створює новий `Property` + `ExternalProperty`
   - Якщо знайдено — оновлює дані (ціна, площа, статус, координати)
   - Зберігає `raw_data` в `ExternalProperty.raw_data` (історія)
4. Обробка зображень: завантажує фото з CRM, конвертує в Webp
5. Логування: скільки створено, оновлено, видалено, помилок

## Верифікація

1. `python manage.py sync_crm_properties` — об'єкти з CRM з'являються в базі
2. Повторний sync — дублікати НЕ створюються, дані оновлюються
3. `raw_data` зберігається для кожної синхронізації (історія)
4. React `/search/` показує синхронізовані об'єкти
5. `npm run lint` — без помилок
6. `npm run build` — успішна збірка
